Firewall Educational Platform

Comprehensive Project Report & Analysis

Authored by: Antigravity AI Platform

1. Executive Summary

The Firewall Educational Platform is a sophisticated web application designed to bridge the gap between theoretical cybersecurity knowledge and practical implementation. It provides a safe, sandboxed environment for students and professionals to observe, execute, and analyze common web-based cyber attacks and the defensive mechanisms employed by modern firewalls.

The platform features a multi-tiered architecture that includes a realistic target e-commerce server, a central monitoring dashboard, and a simulation engine capable of executing 8 distinct types of cyber attacks.

2. System Architecture

The project follows a distributed microservices-inspired architecture to ensure separation of concerns and a realistic testing environment.

1. Frontend Application (Port 5173)

Built with React and Vite, it serves as the command center for launching attacks and viewing educational content. It communicates with the Backend API to trigger simulations.

2. Backend API Server (Port 5001)

An Express.js server that handles the business logic, manages logs in MongoDB, and acts as the "Firewall Controller" that decides which traffic to block or allow.

3. Target Victim Server (Port 3001)

The "ShopVictim" server—a mock e-commerce site intentionally left vulnerable to demonstrate the real-world impact of attacks on data and user sessions.

4. Database (MongoDB Atlas)

A cloud-hosted database that stores simulation logs, firewall rules, and attack metadata for persistent tracking and analysis.

3. Technology Stack

Frontend React.js, Vite, Tailwind CSS, Axios
Backend Node.js, Express.js, Winston (Logging)
Database MongoDB Atlas, Mongoose ODM
Deployment Vercel (Serverless Functions)

5. Deployment Strategy

The platform is optimized for both local development and professional cloud hosting:

Local Deployment

  • npm run install-all: Automates dependency installation for all 3 sub-projects.
  • npm run dev: Uses `concurrently` to start all 3 servers in a single terminal session.

Cloud Deployment (Vercel)

Each component is deployed as a separate Vercel project. The frontend uses Vercel Rewrites to proxy API requests to the backend, while the backend utilizes environment variables to securely link to the MongoDB Atlas cluster and the target server.

6. Conclusion

The Firewall Educational Platform successfully demonstrates the critical importance of multi-layered security. By providing a "safe-to-fail" environment, it empowers users to understand not just HOW attacks happen, but WHY defensive configurations like firewalls, rate limiters, and input validators are non-negotiable in modern web development.
